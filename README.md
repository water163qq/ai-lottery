# AI 智能选号

一个基于多维数据分析的彩票号码生成应用。采用手机 App 布局（底部导航 + 多页面），支持双色球与大乐透，纯前端实现、零运行时依赖，并提供 Android 安装包工程。

> 彩票每期开奖均为独立随机事件，历史数据与任何算法都无法预测未来结果。本项目仅供技术演示与娱乐，请理性购彩，未满 18 周岁禁止购彩。

## 功能

- **数据分析**：冷热号识别、遗漏排行、号码频率分布图、和值走势图，统计窗口 30 / 50 / 100 / 全部可切换，图表随窗口联动
- **智能生成**：智能平衡、追热、追冷、遗漏回补、纯随机五种策略，支持批量生成 1 / 5 / 10 注
- **约束过滤**：和值区间、奇偶比例、区间均衡、限制三连号
- **定胆 / 杀号**：锁定必含号码与排除号码，作为硬约束参与生成
- **手选号码**：点击选球、随机补全、一键收藏
- **收藏夹**：localStorage 本地持久化，按彩种独立保存，支持批量检票
- **模拟开奖**：摇奖机式滚动定格动画，对比命中情况并按官方规则提示奖级
- **最新资讯**：公开最新开奖号码、销售额、奖池与一等奖注数，并汇总彩票新闻
- **战绩统计**：摇号次数、命中次数、命中率、最佳奖级，按彩种独立保存

## 本地运行

```bash
python3 -m http.server 8000
```

访问 `http://localhost:8000`。

更新开奖数据与资讯（会重写 `js/livedata.js`）：

```bash
python3 scripts/fetch-lottery-data.py
```

## 数据来源

| 彩种 | 来源 | 说明 |
|---|---|---|
| 双色球 | 中国福利彩票官方开奖接口 | 最近 500 期，含日期、销售额、奖池、一等奖注数 |
| 大乐透 | 500.com 历史开奖表 | 最近 500 期，含日期、销售额、一等奖注数与奖金 |

数据与新闻由 GitHub Actions 每日定时抓取并提交，抓取失败时保留上一份有效数据，应用端始终能渲染。

## 自动构建与发布

| 工作流 | 触发 | 作用 |
|---|---|---|
| `build.yml` | push / PR / `v*` 标签 / 手动 | 构建并校验 APK 与 Web 源码包；打标签时自动发布 Release |
| `update-data.yml` | 每日定时 / 手动 | 抓取最新开奖数据与资讯并提交 |

发布新版本：

```bash
git tag v1.1.0
git push origin v1.1.0
```

签名密钥通过仓库 Secrets 注入（`KEYSTORE_BASE64`、`KEYSTORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD`），密钥文件本身不入库。

## 核心算法

- **加权无放回抽样**：Efraimidis-Spirakis 指数键法，`key = -ln(U) / w`
- **智能平衡评分**：按和值偏离度、区间均匀度、奇偶比、连号长度、冷热搭配加权打分，从候选中择优
- **遗漏回补**：号码权重按当前遗漏相对理论平均遗漏（`pool/pick - 1`）的偏离呈高斯分布
