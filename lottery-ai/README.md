# AI 智能选号

一个基于多维数据分析的彩票号码生成 Web 应用，采用手机 App 布局（底部导航 + 多页面切换），支持双色球与大乐透，纯前端实现，零依赖。

## 页面结构

底部导航分为四个页面：

- **分析**：冷热号、遗漏排行、频率分布图、和值走势、历史开奖
- **选号**：策略生成、约束过滤、定胆杀号、手选号码
- **开奖**：模拟摇号对比与战绩统计
- **收藏**：收藏号码管理与批量检票

## 功能

- **AI 数据分析**：基于内置 1200 期模拟开奖数据，提供冷热号识别、遗漏排行、号码频率分布图、和值走势图，统计窗口可切换（30 / 50 / 100 / 全部）
- **智能生成**：5 种策略（智能平衡、追热、追冷、遗漏回补、纯随机），支持批量生成 1 / 5 / 10 注
- **约束过滤**：和值区间、奇偶比例、区间均衡、限制三连号
- **定胆 / 杀号**：锁定必含号码与排除号码，作为硬约束参与生成，数量冲突时给出提示
- **手选号码**：点击选球、随机补全、一键收藏
- **收藏夹**：localStorage 本地持久化，按彩种分开保存，支持批量检票
- **模拟开奖**：摇号动画，对比生成结果 / 手选号码 / 新机选的命中情况并提示奖级
- **模拟战绩**：统计摇号次数、命中次数、命中率与最佳奖级，按彩种独立保存

## 项目结构

```
lottery-ai/
  index.html        页面结构
  css/style.css     深色主题样式
  js/data.js        彩种配置、确定性伪随机引擎、模拟历史数据
  js/engine.js      统计分析、加权抽样、评分与奖级映射
  js/app.js         界面交互、Canvas 图表、本地存储
```

## 本地运行

```bash
cd lottery-ai
python3 -m http.server 8000
```

访问 `http://localhost:8000`。

## 核心算法说明

- **加权无放回抽样**：Efraimidis-Spirakis 指数键法，`key = -ln(U) / w`，按权重有放回等效抽样后取前 k 小
- **智能平衡评分**：对候选注按和值偏离度、区间均匀度、奇偶比、连号长度、冷热搭配加权打分，从大量候选中择优
- **遗漏回补**：号码权重按当前遗漏相对理论平均遗漏（`pool/pick - 1`）的偏离呈高斯分布
